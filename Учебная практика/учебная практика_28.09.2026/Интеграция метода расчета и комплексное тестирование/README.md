# Форма расчёта материалов

Отдельное окно поверх CRM: ввёл типы, количество и параметры — получил «Требуется материала, шт.: N».

Кнопка «Расчёт материалов» на главном экране (в папке истории). Есть фабрика соединения — считаем по БД, нет — по справочнику в памяти. Ошибка ввода или `-1` от формулы — диалог с понятным текстом, приложение не падает.

Логика разбора полей и показа результата вынесена отдельно, чтобы её можно было проверить без живого Tk.
