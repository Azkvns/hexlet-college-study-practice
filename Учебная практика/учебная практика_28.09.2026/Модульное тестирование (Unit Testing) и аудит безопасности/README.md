# Тесты и аудит

Сюда собраны unit-тесты и мелочи безопасности.

`test_material_calculator.py` — пять кейсов формулы (эталон 92, округление вверх, битые типы и параметры). `test_error_log.py` — запись в `app.log` с датой и временем, без затирания старых строк. `test_sql_injection.py` — по исходникам проверяем, что SQL идёт с `%s`, а не через склейку строк.

`error_log.log_error` вызывается из `except` истории и формы калькулятора: сначала лог, потом диалог. Штатный `-1` от расчёта в лог не пишем.
