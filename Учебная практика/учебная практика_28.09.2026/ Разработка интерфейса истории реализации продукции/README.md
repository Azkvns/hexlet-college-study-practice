# История реализации

Здесь лежит рабочий CRM и окно истории продаж.

Как пользоваться: в списке кликнуть карточку партнёра, нажать «История продаж». Откроется таблица — наименование, количество, дата. Без выбора партнёра приложение скажет об этом и окно не откроет. Двойной клик по карточке по-прежнему открывает редактирование.

Запрос к БД параметризованный (`%s`), данные тянутся через JOIN отгрузок и заказов. Запуск: `python app.py` (нужны PostgreSQL и зависимости из `requirements.txt`).
