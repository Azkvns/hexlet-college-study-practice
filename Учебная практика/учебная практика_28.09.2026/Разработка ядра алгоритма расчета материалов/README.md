# Ядро расчёта материалов

Чистая формула без интерфейса: сколько сырья нужно на выпуск партии.

Считаем `param_1 × param_2 × коэффициент типа продукции × количество`, затем накидываем процент брака материала и округляем вверх (`ceil`). Некорректный вход (нет типа, ноль/минус, не то количество) — возвращаем `-1`, без исключений.

Справочники: в памяти для тестов (`MemoryMaterialCatalog`) и из таблиц `product_types` / `material_types` (`DbMaterialCatalog`, схема в `material_schema.sql`). Сама функция — `calculate_material_amount` в `material_calculator.py`.
